# SkyStore - Интернет-магазин продуктов

##  Описание проекта

SkyStore - это учебный проект интернет-магазина, разрабатываемый на Django. Проект предназначен для продажи цифровых продуктов: плагинов, скриптов, ботов, веб-приложений и других программных решений.

Проект создается в рамках курса по Django и будет постепенно расширяться функциональностью на протяжении всего обучения. В итоге планируется получить полноценный проект для портфолио.

## Текущий функционал

### Реализовано:
-  Главная страница с каталогом товаров
-  Страница контактов с формой обратной связи
-  Адаптивный дизайн на Bootstrap 5
-  Маршрутизация URL (главная страница и контакты)
- Обработка формы обратной связи с выводом сообщения об успехе
-  Динамическое отображение товаров из базы данных (контекст)


##  Технологии

- **Python** 3.14+
- **Django** 6.1.1
- **Bootstrap** 5.3
- **SQLite** (разработка)
- **Git** (система контроля версий)
